# 中文代码入口

在仓库根目录运行，使用 Python 3.13 和根目录 `requirements.txt` 中的版本。输入字段说明见 `data/schema`。五份授权工作簿命名为 `2021.xlsx` 至 `2025.xlsx`，放入 `data/private/original`。

```powershell
python code/zh/算法自检.py
python code/zh/字段核对.py --数据目录 data/private/original --结果目录 results/generated/zh
python code/zh/完整实验.py --数据目录 data/private/original --结果目录 results/generated/zh --并行数 4
python code/zh/输出复核.py --结果目录 results/generated/zh
```

也可运行 `code/zh/运行实验.ps1`，通过 `-Python`、`-数据目录`、`-结果目录` 和 `-并行数` 指定环境。输入、代码或软件指纹变化时使用新的结果目录。

`重新出图.py` 需要本地结果目录中的 `私密记录_禁止公开/绘图固定输入.joblib`。工作簿可使用 `openpyxl` 后备导出，设置 `WORKBOOK_EXPORT_BACKEND=openpyxl` 可直接选择该方式。

`交付整理.py` 仅整理代码与字段结构，不复制实际结果表或图件，不执行网络上传。新生成的结果和私密缓存保留在本地，不纳入公开仓库。
